Notes on A Probability Path (Resnick)

Chap 6, Convergence Concepts

Summary

The main topic of this chapter is to discuss the relationship between different kinds of convergence, so the graph below will be updated as we go deeper into the chapter. Further, many of the exercises are also about this topic, so we will summarize them here.

\[ \begin{array}{ccccc} \text{Pointwise} & \xrightarrow{\text{Always}} & \text{Almost Sure (a.s.)} & \xrightarrow{\text{Always}} & \text{Probability (P)} \\ & \xleftarrow[\text{Example 6.1.1}]{\text{Fails}} & & \xleftarrow[\text{Example 6.2.1}]{\text{Fails}} & \end{array} \]

we can still recover a.s. convergence under extra conditions, such as:

  • \(\{X_n\}\) is monotone (Ex 1),
  • \(\Omega\) is discrete (Ex 17).

Also, if \(X_n \xrightarrow{P} X\), then every subsequence contains a further subsequence converging a.s. to \(X\).

Further, we get metrics that metrize convergence in probability on \(L^0\) modulo a.s. equality:

  1. \[ d(X,Y)=E\left(\frac{|X-Y|^p}{1+|X-Y|^p}\right), \qquad p>0 \] (Ex 12),

  2. \[ \rho(X,Y)=\inf\{\delta>0:\, P(|X-Y|\ge \delta)\le \delta\} \] (the Ky Fan metric, Ex 25).

By Theorem 6.3.1, every sequence that is Cauchy in probability converges in probability, so any metric generating convergence in probability is complete.

Proposition 6.1.1

In Proposition 6.1.1, the author explicitly construct an exception set for teaching propose, however we can do it in another way:

For any constant \(c\), we have \[ P(M_n\leq c)=P(\max_{1\leq i\leq n}X_n\leq c)=\prod_{i=1}^nP(X_i\leq c)=F^n(c)\to0. \]

What we want to prove is \[ P(M_n\to\infty)=1 \] Since \(M_n\) is increasing with \(n\), so \(M_n\to\sup_n M_n\), therefore it is suffice to prove \[ P(\sup_n M_n=\infty)=1 \] or \[ P(\sup_n M_n<\infty)=0 \]

Note that \[ \{\sup_n M_n<\infty\}=\bigcup_{m\in\mathbb Z}\bigcap_{n=1}^\infty\{M_n\leq m\} \] and for any \(m\), \[ P(\bigcap_{n=1}^\infty\{M_n\leq m\})=\lim_{n\to\infty}P(M_n\leq m)=0 \] so \[ P(\bigcup_{m\in\mathbb Z}\bigcap_{n=1}^\infty\{M_n\leq m\})\leq\sum_{m\in\mathbb Z}P(\bigcap_{n=1}^\infty\{M_n\leq m\})=0. \] Therefore \(P(\sup_n M_n<\infty)=0\), that is \[ M_n\to\infty\quad \text{a.s.} \]

Theorem 6.2.1 (Convergence a.s. implies convergence i.p.)

Since \(X_n\to X\) a.s., that is \[ P(\{\omega:X_n(\omega)\to X(\omega)\})=1 \] and we can rewrite \(\{\omega:X_n(\omega)\to X(\omega)\}\) as \[ \{\omega:X_n(\omega)\to X(\omega)\}=\bigcap_{k=1}^\infty\bigcup_{N=1}^\infty\bigcap_{n=N}^\infty\{\omega:|X_n(\omega)-X(\omega)|\leq\frac1k\} \] so \[ P(\bigcap_{k=1}^\infty\bigcup_{N=1}^\infty\bigcap_{n=N}^\infty\{\omega:|X_n(\omega)-X(\omega)|\leq\frac1k\})=1 \] and \[ P(\bigcup_{k=1}^\infty\bigcap_{N=1}^\infty\bigcup_{n=N}^\infty\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=0, \] that is, for any \(k\in\mathbb Z\), we have \[ P(\bigcap_{N=1}^\infty\bigcup_{n=N}^\infty\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=P(\limsup_n\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=0, \] keep in mind that what we want is \[ \lim_{n\to\infty}P(\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=0, \] denote \(A_n^{(k)}:=\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\}=\{|X_n-X|>\frac1k\}\), for every \(N\) and every \(n\geq N\), we have \[ A_n^{(k)}\subseteq\bigcup_{m\geq N}^\infty A_m^{(k)} \] so \[ P(A_n^{(k)})\leq P(\bigcup_{m\geq N}^\infty A_m^{(k)}) \] therefore \[ \sup_{n\ge N} P(A_n^{(k)})\leq P(\bigcup_{m\geq N}^\infty A_m^{(k)}) \] so \[ \lim_{N\to\infty}\sup_{n\ge N} P(A_n^{(k)})\leq \lim_{N\to\infty}P(\bigcup_{m\geq N}^\infty A_m^{(k)})=P(\limsup_{m}\{|X_m-X|>\frac1k\})=0 \] so we get \[ \lim_{n\to\infty}P(\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=0, \] since the probability of supreme of tail goes to \(0\), then the probability of each term of tail should goes to \(0\) as well.

For the last step, we still need it is true for any \(\varepsilon>0\), not just \(\frac1k\), we can select \(k\) such that \(\frac1k\leq\varepsilon\), so \[ \{|X_n-X|>\varepsilon\}\subseteq\{|X_n-X|>\frac1k\}, \] so we have for any \(\varepsilon>0\) \[ \lim_{n\to\infty}P(\{|X_n-X|>\varepsilon\})\leq\lim_{n\to\infty}P(\{|X_n-X|>\frac1k\})=0. \]

(c) \(\to\) (b)

What we have:

  • \(\{X_n\}\) is uniformly integrable;
  • \(X_n \xrightarrow{P} X\).

What we want:

\[ E|X_n-X_m| \to 0 \qquad (n,m\to\infty), \]

that is, \(\{X_n\}\) is \(L_1\)-Cauchy.

Fix \(\varepsilon>0\), and define

\[ A_{n,m} := \{|X_n-X_m|>\varepsilon\}. \]

Then

\[ \int |X_n-X_m|\,dP = \int_{A_{n,m}^c} |X_n-X_m|\,dP + \int_{A_{n,m}} |X_n-X_m|\,dP. \]

On \(A_{n,m}^c\), we have \(|X_n-X_m|\le \varepsilon\), so

\[ \int_{A_{n,m}^c} |X_n-X_m|\,dP \le \varepsilon. \]

Also, on \(A_{n,m}\),

\[ |X_n-X_m|\le |X_n|+|X_m|, \]

so

\[ \int_{A_{n,m}} |X_n-X_m|\,dP \le \int_{A_{n,m}} |X_n|\,dP + \int_{A_{n,m}} |X_m|\,dP. \]

Hence

\[ \int |X_n-X_m|\,dP \le \varepsilon + \int_{A_{n,m}} |X_n|\,dP + \int_{A_{n,m}} |X_m|\,dP. \]

Since \(X_n \xrightarrow{P} X\), the sequence \(\{X_n\}\) is Cauchy in probability, so

\[ P(A_{n,m}) = P(|X_n-X_m|>\varepsilon)\to 0 \qquad (n,m\to\infty). \]

Since \(\{X_n\}\) is uniformly integrable, by Theorem 6.5.1 it is uniformly absolutely continuous. Therefore, for the given \(\varepsilon>0\), there exists \(\delta>0\) such that whenever \(P(A)<\delta\),

\[ \sup_n \int_A |X_n|\,dP < \varepsilon. \]

Thus, for \(n,m\) large enough so that \(P(A_{n,m})<\delta\), we have

\[ \int_{A_{n,m}} |X_n|\,dP < \varepsilon, \qquad \int_{A_{n,m}} |X_m|\,dP < \varepsilon. \]

Therefore,

\[ \int |X_n-X_m|\,dP < \varepsilon+\varepsilon+\varepsilon = 3\varepsilon \]

for all sufficiently large \(n,m\). Hence

\[ E|X_n-X_m| \to 0, \]

so \(\{X_n\}\) is \(L_1\)-Cauchy.

(a) \(\to\) (c)

What we have:

\[ X_n \xrightarrow{L_1} X. \]

What we want:

  • \(\{X_n\}\) is uniformly integrable;
  • \(X_n \xrightarrow{P} X\).

First, since \(X_n \xrightarrow{L_1} X\), we have

\[ E|X_n-X| \to 0. \]

So for every \(\varepsilon>0\), Markov’s inequality gives

\[ P(|X_n-X|>\varepsilon) \le \frac{1}{\varepsilon} E|X_n-X| \to 0. \]

Hence

\[ X_n \xrightarrow{P} X. \]

Now we prove \(\{X_n\}\) is uniformly integrable.

First, for every \(n\),

\[ \int |X_n|\,dP \le \int |X_n-X|\,dP + \int |X|\,dP. \]

Since \(\int |X_n-X|\,dP \to 0\) and \(X\in L_1\), it follows that

\[ \sup_n \int |X_n|\,dP < \infty. \]

Next, we prove uniform absolute continuity.

Fix \(\varepsilon>0\). Since \(E|X_n-X|\to 0\), there exists \(N_\varepsilon\) such that for all \(n\ge N_\varepsilon\),

\[ \int |X_n-X|\,dP < \frac{\varepsilon}{2}. \]

Therefore, for any \(A\in\mathcal{B}\) and any \(n\ge N_\varepsilon\),

\[ \int_A |X_n|\,dP \le \int_A |X_n-X|\,dP + \int_A |X|\,dP \le \int |X_n-X|\,dP + \int_A |X|\,dP < \frac{\varepsilon}{2} + \int_A |X|\,dP. \]

Since \(X\in L_1\), the singleton family \(\{X\}\) is uniformly integrable, so there exists \(\delta_1>0\) such that

\[ P(A)<\delta_1 \quad\Longrightarrow\quad \int_A |X|\,dP < \frac{\varepsilon}{2}. \]

Hence, if \(P(A)<\delta_1\), then for all \(n\ge N_\varepsilon\),

\[ \int_A |X_n|\,dP < \varepsilon. \]

So we have shown

\[ \sup_{n\ge N_\varepsilon}\int_A |X_n|\,dP < \varepsilon \qquad \text{whenever } P(A)<\delta_1. \]

Now consider the finite family

\[ \{|X_1|,\dots,|X_{N_\varepsilon-1}|\}. \]

Since each \(X_n\in L_1\) and the family is finite, it is uniformly integrable. Therefore, there exists \(\delta_2>0\) such that

\[ P(A)<\delta_2 \quad\Longrightarrow\quad \sup_{1\le n < N_\varepsilon}\int_A |X_n|\,dP < \varepsilon. \]

Let

\[ \delta := \delta_1\wedge \delta_2. \]

Then whenever \(P(A)<\delta\), we have both

\[ \sup_{n\ge N_\varepsilon}\int_A |X_n|\,dP < \varepsilon \]

and

\[ \sup_{1\le n < N_\varepsilon}\int_A |X_n|\,dP < \varepsilon. \]

Therefore,

\[ \sup_n \int_A |X_n|\,dP < \varepsilon \qquad \text{whenever } P(A)<\delta. \]

So \(\{X_n\}\) is uniformly absolutely continuous. Together with

\[ \sup_n E|X_n|<\infty, \]

Theorem 6.5.1 implies that \(\{X_n\}\) is uniformly integrable.

Hence we have proved:

  • \(\{X_n\}\) is uniformly integrable;
  • \(X_n \xrightarrow{P} X\).

That is, (c) holds.

Theorem 6.6.2

(b) \(\to\) (a)

Suppose \(\{X_n\}\) is Cauchy in \(L_p\). We want to show that there exists \(X \in L_p\) such that

\[ \|X_n-X\|_p \to 0. \]

Since \(\{X_n\}\) is Cauchy in \(L_p\), for each \(j \ge 1\) there exists \(N_j\) such that

\[ m,n \ge N_j \quad\Longrightarrow\quad \|X_n-X_m\|_p < 2^{-j}. \]

Without loss of generality, take \(N_1 < N_2 < \cdots\), and define

\[ n_j := N_j. \]

Then \(n_j \to \infty\), and since both \(n_j\) and \(n_{j+1}\) are at least \(N_j\), we have

\[ \|X_{n_{j+1}}-X_{n_j}\|_p < 2^{-j} \qquad (j \ge 1). \]

Now define

\[ Y_K := \sum_{j=1}^K |X_{n_{j+1}}-X_{n_j}|, \qquad Y := \sum_{j=1}^\infty |X_{n_{j+1}}-X_{n_j}|. \]

By Minkowski’s inequality,

\[ \|Y_K\|_p \le \sum_{j=1}^K \|X_{n_{j+1}}-X_{n_j}\|_p < \sum_{j=1}^K 2^{-j} \le 1. \]

Hence

\[ E(Y_K^p)=\|Y_K\|_p^p \le 1. \]

Since \(Y_K \uparrow Y\), we also have \(Y_K^p \uparrow Y^p\), so by the Monotone Convergence Theorem,

\[ E(Y^p)=\lim_{K\to\infty} E(Y_K^p)\le 1. \]

Therefore \(Y \in L_p\), and in particular \(Y<\infty\) almost surely.

So for almost every \(\omega\),

\[ \sum_{j=1}^\infty |X_{n_{j+1}}(\omega)-X_{n_j}(\omega)|<\infty. \]

Hence the series

\[ \sum_{j=1}^\infty \bigl(X_{n_{j+1}}(\omega)-X_{n_j}(\omega)\bigr) \]

converges absolutely, and therefore converges. Since its \(K\)th partial sum is

\[ \sum_{j=1}^K (X_{n_{j+1}}-X_{n_j}) = X_{n_{K+1}}-X_{n_1}, \]

it follows that \(\{X_{n_j}\}\) converges almost surely. Define

\[ X := \lim_{j\to\infty} X_{n_j} \qquad \text{a.e.} \]

Next, for each \(K\) we have

\[ X_{n_{K+1}}-X_{n_1}=\sum_{j=1}^K (X_{n_{j+1}}-X_{n_j}), \]

so

\[ |X_{n_{K+1}}-X_{n_1}| \le \sum_{j=1}^K |X_{n_{j+1}}-X_{n_j}| \le Y. \]

Passing to the limit \(K\to\infty\), we get

\[ |X-X_{n_1}| \le Y \qquad \text{a.e.} \]

Hence

\[ |X| \le |X_{n_1}| + Y. \]

Since \(X_{n_1} \in L_p\) and \(Y \in L_p\), it follows that \(X \in L_p\).

Now define the tails

\[ T_j := \sum_{k=j}^\infty |X_{n_{k+1}}-X_{n_k}|. \]

Then \(T_j \downarrow 0\) almost surely, and \(0 \le T_j \le Y\). Also,

\[ |X-X_{n_j}| \le T_j \qquad \text{a.e.} \]

Therefore,

\[ |X-X_{n_j}|^p \le T_j^p \le Y^p. \]

Since \(Y^p \in L_1\) and \(T_j^p \to 0\) almost surely, the Dominated Convergence Theorem gives

\[ E|X-X_{n_j}|^p \to 0. \]

Thus

\[ \|X_{n_j}-X\|_p \to 0. \]

Finally, we extend from the subsequence to the whole sequence. Fix \(\varepsilon>0\). Since \(X_{n_j}\to X\) in \(L_p\), there exists \(j\) such that

\[ \|X_{n_j}-X\|_p < \frac{\varepsilon}{2}. \]

Since \(\{X_n\}\) is Cauchy in \(L_p\), there exists \(N\) such that

\[ m,n \ge N \quad\Longrightarrow\quad \|X_n-X_m\|_p < \frac{\varepsilon}{2}. \]

Choose \(j\) large enough so that \(n_j \ge N\). Then for every \(n \ge N\),

\[ \|X_n-X\|_p \le \|X_n-X_{n_j}\|_p + \|X_{n_j}-X\|_p < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon. \]

Hence

\[ \|X_n-X\|_p \to 0. \]

So \(\{X_n\}\) converges in \(L_p\), and therefore \(L_p\) is complete.

Theorem 6.3.1(a)

We focus on the part that if \(\{X_n\}\) is Cauchy in probability, then \(\{X_n\}\) converges in probability.

When we only have “for any \(\varepsilon,\delta>0\), there exists \(n_0\) such that for all \(r,s\geq n_0\), \(P(|X_r-X_s|>\varepsilon)<\delta\)”, it is hard to get a convergent result from the void, therefore we need to get help from another space that is when Cauchy then convergent, i.e. a complete space, luckily, \(\mathbb R\) is complete, so we can try to construct the required convergent result from \(\{X_n(\omega)\}\subseteq\mathbb R\), however, Example 6.2.1 gave us a counter example such that convergence i.p. but not a.s., so we can not directly use something like \(\lim_{n\to\infty}X_n\). So the idea is to construct a sub-sequence such that the probability that the difference of consecutive terms are large than some value is decreasing geometrically, that is \[ P(|X_{n_{k+1}}-X_{n_k}|>2^{-k})\le 2^{-k}. \] then by Borel-Cantelli, we get a exception set that this sub-sequence is not Cauchy. That is, we construct a sub-seq is Cauchy a.s., and by the completeness of the real numbers, we construct a convergent result \(X\), then by triangle inequality, the total sequence converges to our \(X\) i.p.

Summary for Theorem 6.4.1

What we have is:

  1. \(X_1,X_2,\dots\) are iid.
  2. \(F\) is strictly increasing at \(q:=F^{\leftarrow}(p)\), so for every \(\varepsilon>0\), \[ F(q-\varepsilon)<p<F(q+\varepsilon). \]

What we want to show is: \[ X^{(n)}_{[np]} \xrightarrow{P} F^{\leftarrow}(p). \]

The idea is:

  1. By the definition of convergence in probability, divide \[ P\left(\left|X^{(n)}_{[np]}-q\right|>\varepsilon\right) \] into two tails: \[ P\left(X^{(n)}_{[np]}>q+\varepsilon\right) \quad\text{and}\quad P\left(X^{(n)}_{[np]}<q-\varepsilon\right). \]

  2. Translate both tails into events involving \(F_n\), because we know \[ F_n(x)\xrightarrow{P}F(x). \]

  3. Use both \[ F_n(x)\xrightarrow{P}F(x) \quad\text{and}\quad \frac{[np]}{n}\to p, \] together with \[ F(q-\varepsilon)<p<F(q+\varepsilon), \] to create a fixed positive gap, then bound each tail by a probability of the form \[ P\bigl(|F_n(x)-F(x)|>\text{positive constant}\bigr)\to0. \]

Further, the reason that we need \(F\) is strictly increasing is because we need something that is locally unique to converge to.

Ex 2

Let \(\{X_n\}\) be iid, \(EX_n=\mu\), \(\operatorname{Var}(X_n)=\sigma^2\). Set \[ \bar X = \sum_{i=1}^n X_i/n. \] Show \[ \frac{1}{n}\sum_{i=1}^n (X_i-\bar X)^2 \xrightarrow{P} \sigma^2. \]

\(\textbf{Answer:}\)

Let \(\{X_i\}_{i\ge1}\) be iid with \(E(X_1)=\mu\) and \(\operatorname{Var}(X_1)=\sigma^2<\infty\).

Define \[ Y_n = \frac{1}{n}\sum_{i=1}^n (X_i - \bar X_n)^2, \quad \text{where} \quad \bar X_n = \frac{1}{n}\sum_{i=1}^n X_i. \]

We want to show \[ Y_n \xrightarrow{P} \sigma^2. \]

  • Step 1: Algebraic decomposition

We write \[ Y_n = \frac{1}{n}\sum_{i=1}^n X_i^2 - \bar X_n^2. \]

  • Step 2: Convergence of the first term

Let \(Z_i = X_i^2\). Then \(\{Z_i\}\) are iid and \[ E|Z_1| = E(X_1^2) < \infty. \]

By Khinchin’s Weak Law of Large Numbers (Chapter 7), \[ \frac{1}{n}\sum_{i=1}^n X_i^2 = \frac{1}{n}\sum_{i=1}^n Z_i \xrightarrow{P} E(Z_1) = E(X_1^2). \]

  • Step 3: Convergence of the second term

By the Weak Law of Large Numbers (finite variance version), \[ \bar X_n \xrightarrow{P} \mu. \]

Since \(x \mapsto x^2\) is continuous, by the Continuous Mapping Theorem, \[ \bar X_n^2 \xrightarrow{P} \mu^2. \]

  • Step 4: Conclusion

Combining the two convergences, \[ Y_n = \frac{1}{n}\sum_{i=1}^n X_i^2 - \bar X_n^2 \xrightarrow{P} E(X_1^2) - \mu^2. \]

Since \[ E(X_1^2) - \mu^2 = \operatorname{Var}(X_1) = \sigma^2, \]

we conclude \[ Y_n \xrightarrow{P} \sigma^2. \]

\(\textbf{Note:}\) This exercise requires the knowledge from chapter 7, which is the Khintchin’s WLLN under the first moment hypothesis in page 205, if we don’t use it, we still need to use the truncation method to by pass the \(E(X_i^4)\) situation.

When \(X(\omega)+Y(\omega)=0\), both sides are \(0\), so the inequality holds.

When \(X(\omega)+Y(\omega)>0\), we have \[ 0\le \frac{X}{X+Y}\le 1, \qquad 0\le \frac{Y}{X+Y}\le 1. \]

Since \(0\le p\le 1\), for \(0\le t\le 1\), \[ t^p\ge t. \]

So \[ \left(\frac{X}{X+Y}\right)^p + \left(\frac{Y}{X+Y}\right)^p \ge \frac{X}{X+Y} + \frac{Y}{X+Y} = 1. \]

Multiplying by \((X+Y)^p\), we get \[ X^p+Y^p\ge (X+Y)^p. \]

Therefore, \[ (X+Y)^p\le X^p+Y^p. \]

Taking expectation, \[ E((X+Y)^p)\le E(X^p)+E(Y^p). \]
