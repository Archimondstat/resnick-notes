Alternative proof

Proposition 6.1.1

In Proposition 6.1.1, the author explicitly construct an exception set for teaching propose, however we can do it in another way:

For any constant \(c\), we have \[ P(M_n\leq c)=P(\max_{1\leq i\leq n}X_n\leq c)=\prod_{i=1}^nP(X_i\leq c)=F^n(c)\to0. \]

What we want to prove is \[ P(M_n\to\infty)=1 \] Since \(M_n\) is increasing with \(n\), so \(M_n\to\sup_n M_n\), therefore it is suffice to prove \[ P(\sup_n M_n=\infty)=1 \] or \[ P(\sup_n M_n<\infty)=0 \]

Note that \[ \{\sup_n M_n<\infty\}=\bigcup_{m\in\mathbb Z}\bigcap_{n=1}^\infty\{M_n\leq m\} \] and for any \(m\), \[ P(\bigcap_{n=1}^\infty\{M_n\leq m\})=\lim_{n\to\infty}P(M_n\leq m)=0 \] so \[ P(\bigcup_{m\in\mathbb Z}\bigcap_{n=1}^\infty\{M_n\leq m\})\leq\sum_{m\in\mathbb Z}P(\bigcap_{n=1}^\infty\{M_n\leq m\})=0. \] Therefore \(P(\sup_n M_n<\infty)=0\), that is \[ M_n\to\infty\quad \text{a.s.} \]

Theorem 6.2.1 (Convergence a.s. implies convergence i.p.)

Since \(X_n\to X\) a.s., that is \[ P(\{\omega:X_n(\omega)\to X(\omega)\})=1 \] and we can rewrite \(\{\omega:X_n(\omega)\to X(\omega)\}\) as \[ \{\omega:X_n(\omega)\to X(\omega)\}=\bigcap_{k=1}^\infty\bigcup_{N=1}^\infty\bigcap_{n=N}^\infty\{\omega:|X_n(\omega)-X(\omega)|\leq\frac1k\} \] so \[ P(\bigcap_{k=1}^\infty\bigcup_{N=1}^\infty\bigcap_{n=N}^\infty\{\omega:|X_n(\omega)-X(\omega)|\leq\frac1k\})=1 \] and \[ P(\bigcup_{k=1}^\infty\bigcap_{N=1}^\infty\bigcup_{n=N}^\infty\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=0, \] that is, for any \(k\in\mathbb Z\), we have \[ P(\bigcap_{N=1}^\infty\bigcup_{n=N}^\infty\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=P(\limsup_n\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=0, \] keep in mind that what we want is \[ \lim_{n\to\infty}P(\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=0, \] denote \(A_n^{(k)}:=\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\}=\{|X_n-X|>\frac1k\}\), for every \(N\) and every \(n\geq N\), we have \[ A_n^{(k)}\subseteq\bigcup_{m\geq N}^\infty A_m^{(k)} \] so \[ P(A_n^{(k)})\leq P(\bigcup_{m\geq N}^\infty A_m^{(k)}) \] therefore \[ \sup_{n\ge N} P(A_n^{(k)})\leq P(\bigcup_{m\geq N}^\infty A_m^{(k)}) \] so \[ \lim_{N\to\infty}\sup_{n\ge N} P(A_n^{(k)})\leq \lim_{N\to\infty}P(\bigcup_{m\geq N}^\infty A_m^{(k)})=P(\limsup_{m}\{|X_m-X|>\frac1k\})=0 \] so we get \[ \lim_{n\to\infty}P(\{\omega:|X_n(\omega)-X(\omega)|>\frac1k\})=0, \] since the probability of supreme of tail goes to \(0\), then the probability of each term of tail should goes to \(0\) as well.

For the last step, we still need it is true for any \(\varepsilon>0\), not just \(\frac1k\), we can select \(k\) such that \(\frac1k\leq\varepsilon\), so \[ \{|X_n-X|>\varepsilon\}\subseteq\{|X_n-X|>\frac1k\}, \] so we have for any \(\varepsilon>0\) \[ \lim_{n\to\infty}P(\{|X_n-X|>\varepsilon\})\leq\lim_{n\to\infty}P(\{|X_n-X|>\frac1k\})=0. \]

Thus \(X_n\to X\) i.p.

Proof idea summarize

It is essentially impossible to recreate every proof in the book on my own, but I think it is still worthy summarizing the idea of proof using my own language.

Theorem 6.3.1(a)

We focus on the part that if \(\{X_n\}\) is Cauchy in probability, then \(\{X_n\}\) converges in probability.

When we only have “for any \(\varepsilon,\delta>0\), there exists \(n_0\) such that for all \(r,s\geq n_0\), \(P(|X_r-X_s|>\varepsilon)<\delta\)”, it is hard to get a convergent result from the void, therefore we need to get help from another space that is when Cauchy then convergent, i.e. a complete space, luckily, \(\mathbb R\) is complete, so we can try to construct the required convergent result from \(\{X_n(\omega)\}\subseteq\mathbb R\), however, Example 6.2.1 gave us a counter example such that convergence i.p. but not a.s., so we can not directly use something like \(\lim_{n\to\infty}X_n\). So the idea is to construct a sub-sequence such that the probability that the difference of consecutive terms are large than some value is decreasing geometrically, that is \[ P(|X_{n_{k+1}}-X_{n_k}|>2^{-k})\le 2^{-k}. \] then by Borel-Cantelli, we get a exception set that this sub-sequence is not Cauchy. That is, we construct a sub-seq is Cauchy a.s., and by the completeness of the real numbers, we construct a convergent result \(X\), then by triangle inequality, the total sequence converges to our \(X\) i.p.

EX 1

  1. Let \(\{X_n\}\) be a monotone sequence of random variables. If \[ X_n \xrightarrow{P} X \] then \[ X_n \xrightarrow{\text{a.s.}} X. \]

(Think subsequences.)

  1. Let \(\{X_n\}\) be any sequence of random variables. Show that \[ X_n \xrightarrow{\text{a.s.}} X \] iff \[ \sup_{k \ge n} |X_k - X| \xrightarrow{P} 0. \]
  1. Points are chosen at random on the circumference of the unit circle. \(Y_n\) is the length of the largest arc not containing any points when \(n\) points are chosen. Show \(Y_n \to 0\) a.s.
  1. Let \(\{X_n\}\) be iid with common distribution \(F(x)\) which satisfies \(F(x_0)=1\), \(F(x)<1\) for \(x<x_0\) with \(x_0<\infty\). Prove \[ \max\{X_1,\dots,X_n\} \uparrow x_0 \] almost surely.

(a)

\(\textbf{My idea:}\) Since \(X_n\xrightarrow{P}X\), then there exists a sub-sequence \(\{X_{n_k}\}\) such that \(X_{n_k}\xrightarrow{a.s.}X\), also, \(\{X_n\}\) is monotone, so the limit in a.s. sense always exists, including \(\pm\infty\), and all its convergent sub-sequences should have the same limit, so we have \(X_n\xrightarrow{a.s.}X\).

\(\textbf{Answer:}\) Since \(X_n\xrightarrow{P}X\), then there exists a sub-sequence \(\{X_{n_k}\}\) such that \(X_{n_k}\xrightarrow{a.s.}X\), also, \(\{X_n\}\) is monotone, so for any \(\omega\in\Omega\) the limit always exists, including \(\pm\infty\), denote \(Y(\omega):=\lim_{n\to\infty}X_n(\omega)\), then we must have \[ \lim_{k\to\infty}X_{n_k}=Y \] therefore \(X=Y\) a.s., that is \[ \lim_{n\to\infty}X_n=X\quad\text{a.s.} \]

\(\textbf{Note:}\) Here we met the crucial difference between a.s. and pointwise, the monotoncity actually guarantees us convergent pointwise, but the subsequence we get is convergent a.s., therefore we cannot treat them as the same thing, so I modify My idea a little.

(b)

\(\textbf{My idea:}\) “\(\Rightarrow\)”: Since \(X_n\xrightarrow{a.s.}X\), we already have that \(X_n\xrightarrow{P}X\), that is for any \(\delta,\varepsilon>0\), there exists \(n_0(\delta,\varepsilon)\) such that when \(n\geq n_0\), we have \[ P(|X_n-X|>\varepsilon)<\delta \] therefore for \(n\geq n_0\), we have \[ P(\sup_{k\geq n}|X_k-X|>\varepsilon)<\delta \] that is \[ \sup_{k\geq n}|X_k-X|\xrightarrow{P}0. \]

“\(\Leftarrow\)”: Let \(Y_n:=\sup_{k\geq n}X_n\), so \(Y_n\) is monotone decreasing with \(n\), since \[ \sup_{k\geq n}|X_k-X|\xrightarrow{P}0. \] and \[ \{|\sup_{k\geq n}X_k-X|>\varepsilon\}\subseteq\{\sup_{k\geq n}|X_k-X|>\varepsilon\} \] so \(\sup_{k\geq n}X_k\xrightarrow{P}X\), by (a), we have \(\sup_{k\geq n}X_k\xrightarrow{a.s.}X\), that is \(X_n\xrightarrow{a.s.}X\).

\(\textbf{Answer:}\)

“\(\Rightarrow\)”: Since \(X_n\xrightarrow{a.s.}X\), so for a.e. \(\omega\in\Omega\), we have \(\sup_{k\geq n}|X_n-X|\downarrow0\), so \[ \sup_{k\geq n}|X_k-X|\xrightarrow{a.s.}0, \] then we have \[ \sup_{k\geq n}|X_k-X|\xrightarrow{P}0, \]

“\(\Leftarrow\)”: Let \(Y_n:=\sup_{k\geq n}|X_k-X|\), then \(Y_n\xrightarrow{P}0\) and \(Y_n\) is monotone decreasing, so \(Y_n\xrightarrow{a.s.}0\), and we have \[ |X_n-X|\leq\sup_{k\geq n}|X_k-X|\xrightarrow{a.s.}0. \]

(c)

\(\textbf{My idea:}\) We can reconsider this question as: select \(n-1\) points in a line with fixed length, and \(Y_n\) be the longest part without any points, since for \(n=1\), the arc is just the total line. Denote the length of the line as \(L\), and each line as \(X_n\), so \(X_n\leq L\), and \(Y_n=\max_{1\leq i\leq n}X_n\), and \(X_n\) are iid, so we can investigate the distribution function of \(Y_n\) \[ P[Y_n\leq y]=P[X_1\leq y,\dots,X_n\leq y]=\prod_{i=1}^nP[X_i\leq y]=F_X^n(y). \] However, since \(X_n\) are upper-bounded, so there exists \(x_0\), such that \(F(x_0)=1\), that is for \(y\geq x_0\), we have \(\sum_{n=1}^\infty F_X^n(y)=\infty\), by Borel-Cantelli, we have \[ P[\{Y_n\leq y\}\ \text{i.o.}]=0. \] \(\textbf{Answer:}\) \(\textbf{Answer:}\) Let the circumference of the circle be \(L\). For any \(\varepsilon>0\), choose \(m\) such that \[ \frac{L}{m}<\varepsilon, \] and divide the circle into \(m\) equal subarcs \(I_1,\dots,I_m\).

If \(Y_n>\varepsilon\), then there exists an empty arc of length greater than \(\varepsilon\). Such an arc must contain at least one of the subarcs \(I_1,\dots,I_m\). Hence \[ \{Y_n>\varepsilon\}\subseteq \bigcup_{i=1}^m \{I_i \text{ contains no point}\}. \]

For each fixed subarc \(I_i\), the probability that one chosen point does not fall into it is \[ 1-\frac{L/m}{L}=1-\frac1m, \] so the probability that none of the \(n\) chosen points falls into it is \[ \left(1-\frac1m\right)^n. \] Therefore, by the union bound, \[ P(Y_n>\varepsilon) \le \sum_{i=1}^m P(I_i \text{ contains no point}) = m\left(1-\frac1m\right)^n \to 0. \] Thus \[ Y_n\xrightarrow{P}0. \]

Also, \(Y_n\) is monotone decreasing, since adding a new point cannot make the longest empty arc longer. Hence by part (a), \[ Y_n\xrightarrow{a.s.}0. \]

\(\textbf{Note:}\) These subarcs are not iid.

(d)

\(\textbf{My idea:}\) Let \(Y_n=\max\{X_1,\dots,X_n\}\), since \(X_n\) are iid, for any \(\varepsilon>0\), we have \[ \begin{aligned} P(|Y_n-x_0|>\varepsilon)&=P(\{Y_n>\varepsilon+x_0\}\cup\{Y_n<x_0-\varepsilon\})\\ &\leq P(\{Y_n>\varepsilon+x_0\})+P(\{Y_n<x_0-\varepsilon\})\\ &=1-P(Y_n\leq x_0+\varepsilon)+\prod_{i=1}^nP(X_i<x_0-\varepsilon)\\ &=1-\prod_{i=1}^nP(X_i\leq x_0+\varepsilon)+\prod_{i=1}^nP(X_i<x_0-\varepsilon)\\ &=1-F^n(x_0+\varepsilon)+F^n((x_0-\varepsilon)-)\\ &\leq F^n(x_0-\varepsilon)\to0 \end{aligned} \] so \(Y_n\xrightarrow{P}x_0\), and \(Y_n\) is increasing with \(n\), by (a), we have \(Y_n\xrightarrow{a.s.}x_0\).

EX 12

Let \(\{X_n\}\) be a sequence of random variables.

  1. If \(X_n \xrightarrow{P} 0\), then for any \(p>0\) \[ \frac{|X_n|^p}{1+|X_n|^p} \xrightarrow{P} 0 \tag{6.21} \] and \[ E\!\left(\frac{|X_n|^p}{1+|X_n|^p}\right)\to 0. \tag{6.22} \]

  2. If for some \(p>0\) \((6.21)\) holds, then \(X_n \xrightarrow{P} 0\).

  3. Suppose \(p>0\). Show \(X_n \xrightarrow{P} 0\) iff \((6.22)\).

(a)

\(\textbf{My idea:}\) Let \[ g(x)=\frac{|x|^p}{1+|x|^p}, \] then \(g(x)\) is continuous, by corollary 6.3.1, since \(X_n\xrightarrow{P}0\), then \(g(X_n)\xrightarrow{P}g(0)=0\), that is \[ \frac{|X_n|^p}{1+|X_n|^p}\xrightarrow{P}0. \] Further, note that \(\frac{|X_n|^p}{1+|X_n|^p}\leq1\in L_1\), by Corollary 6.3.2, we have \[ E\left(\frac{|X_n|^p}{1+|X_n|^p}\right)\to0. \]

(b)

\(\textbf{My idea:}\) Since \(\frac{|X_n|^p}{1+|X_n|^p}\xrightarrow{P}0\), that is for any \(\varepsilon>0\), we have \[ P(\frac{|X_n|^p}{1+|X_n|^p}>\varepsilon)\to0, \] that is \[ P(|X_n|^p>\varepsilon(1+|X_n|^p))\to0 \] since \(1+|X_n|^p\geq1\), then \(\{|X_n|^p>\varepsilon\}\subseteq\{\frac{|X_n|^p}{1+|X_n|^p}>\varepsilon\}\), that is \[ P(|X_n|^p>\varepsilon)\to0 \] so \[ P(|X_n|>\varepsilon^{\frac1p})\to0. \]

\(\textbf{Answer:}\) Note that \(g(x)=\frac{|x|^p}{1+|x|^p}\) is increasing and a 1-1 mapping on \([0,\infty)\), so we have \[ \{\frac{|X_n|^p}{1+|X_n|^p}>\frac{\varepsilon^p}{1+\varepsilon^p}\}=\{|X_n|^p>\varepsilon^p\}=\{|X_n|>\varepsilon\} \] so \[ P(|X_n|>\varepsilon)\to0. \]

\(\textbf{Note:}\) The set relation \(\{|X_n|^p>\varepsilon\}\subseteq\{\frac{|X_n|^p}{1+|X_n|^p}>\varepsilon\}\) in My idea is false.

(c)

\(\textbf{My idea:}\) The “\(\Rightarrow\)” part is in (a)

“\(\Leftarrow\)”

By Markov Inequality, for any \(\varepsilon>0\), we have \[ P\left(\frac{|X_n|^p}{1+|X_n|^p}>\varepsilon\right)\leq\frac{E\left(\frac{|X_n|^p}{1+|X_n|^p}\right)}{\varepsilon}\to0 \]

so \(\frac{|X_n|^p}{1+|X_n|^p}\xrightarrow{P}0\), by (b), we have \(X_n\xrightarrow{P}0\).

\(\textbf{Note:}\) In (c), My idea is correct.

Summary

This exercise essentially gives a natural metric for convergence in probability. On \(L^0\) modulo a.s. equality, for random variables \(X,Y\), define \[ d(X,Y)=E\left(\frac{|X-Y|^p}{1+|X-Y|^p}\right), \qquad p>0. \] This expectation always exists since \[ 0\le \frac{|X-Y|^p}{1+|X-Y|^p}\le 1 \in L^1. \]

According to part (c), we have \[ X_n\xrightarrow{P}X \quad\text{iff}\quad d(X_n,X)\to 0. \]

So this exercise shows that convergence in probability is metrizable on \(L^0\). In this sense, Theorem 6.3.1 can be viewed as a completeness statement for a metric generating convergence in probability.

EX 17

In a discrete probability space, convergence in probability is equivalent to almost sure convergence.

\(\textbf{My idea:}\) Suppose \(X_n\xrightarrow{P}X\), but \(X_n\not\xrightarrow{a.s.}X\), then there exists \(A\in\mathcal B\), \(P(A)>0\) such that for \(\omega\in A\), exists \(\varepsilon_0>0\), for all \(N>0\), exists \(n_0\geq N\), such that \[ |X_n(\omega)-X(\omega)|>\varepsilon_0. \] Since \(\Omega\) is discrete, we always can pick an \(\omega_0\) from \(A\) such that \(P(\omega_0)>0\), so for this \(\omega_0\), there exists \(\varepsilon_0>0\) for all \(N>0\), we always have \(n\geq N\) such that \[ P(\{\omega_0:|X_n(\omega_0)-X(\omega_0)|>\varepsilon_0\})>0, \] that is, for \(N=1\), there is \(n_1\) such that \(|X_{n_1}(\omega_0)-X(\omega_0)|>\varepsilon_0\), and for \(N=n_1+1\), we also have \(n_2\) such that \(|X_{n_k}(\omega_0)-X(\omega_0)|>\varepsilon_0\), by doing so we explicitly construct a sub-sequence \(X_{n_k}\), such that \[ P(\{\omega_0:|X_{n_k}(\omega_0)-X(\omega_0)|>\varepsilon_0\})>0 \] then for this \(\varepsilon_0\), it is contradict to \[ P(|X_n-X|>\varepsilon_0)\to0 \] so \(X_n\xrightarrow{a.s.}X\).

Conversely, we already have \(X_n\xrightarrow{a.s.}X\implies X_n\xrightarrow{P}X\).

\(\textbf{Answer:}\)

“\(\Rightarrow\)”: It is a standard result that almost sure convergence implies convergence in probability in any probability space. Since \(X_n \xrightarrow{a.s.} X\), for any \(\varepsilon > 0\), \(P(|X_n - X| > \varepsilon) \to 0\) as \(n \to \infty\). Therefore, \(X_n \xrightarrow{P} X\).

“\(\Leftarrow\)”: Assume \(X_n \xrightarrow{P} X\). We want to show \(X_n \xrightarrow{a.s.} X\) in a discrete probability space \(\Omega\).

Suppose for the sake of contradiction that \(X_n \not\xrightarrow{a.s.} X\). Let \(A\) be the set of outcomes where convergence fails: \[ A = \left\{\omega \in \Omega : \lim_{n \to \infty} X_n(\omega) \neq X(\omega)\right\} \] By our assumption that almost sure convergence fails, we have \(P(A) > 0\).

Since \(\Omega\) is a discrete probability space, any event is composed of a countable union of disjoint singleton events. Therefore: \[ P(A) = \sum_{\omega \in A} P(\{\omega\}) \] Because \(P(A) > 0\), there must exist at least one specific outcome \(\omega_0 \in A\) such that \(P(\{\omega_0\}) = p_0 > 0\).

Since \(\omega_0 \in A\), the deterministic sequence of real numbers \(X_n(\omega_0)\) does not converge to \(X(\omega_0)\). By the definition of non-convergence, there exists some \(\varepsilon_0 > 0\) such that for any integer \(N > 0\), there exists an \(n \geq N\) satisfying: \[ |X_n(\omega_0) - X(\omega_0)| \geq \varepsilon_0 \] This allows us to explicitly construct a subsequence \(n_k\) such that for all \(k\): \[ |X_{n_k}(\omega_0) - X(\omega_0)| \geq \varepsilon_0 \] Now, consider the event \(B_n = \{\omega \in \Omega : |X_n(\omega) - X(\omega)| \geq \varepsilon_0\}\). For every index in our subsequence \(n_k\), the specific outcome \(\omega_0\) is an element of \(B_{n_k}\). By the monotonicity of probability measures, this implies: \[ P(|X_{n_k} - X| \geq \varepsilon_0) \geq P(\{\omega_0\}) = p_0 > 0 \quad \text{for all } k \] Because there is a subsequence where the probability is bounded below by a strictly positive number \(p_0\), the limit of the sequence of probabilities cannot be zero: \[ \lim_{n \to \infty} P(|X_n - X| \geq \varepsilon_0) \neq 0 \] This directly contradicts our initial assumption that \(X_n \xrightarrow{P} X\). Therefore, our assumption that \(X_n \not\xrightarrow{a.s.} X\) must be false, concluding that \(X_n \xrightarrow{a.s.} X\).

\(\textbf{Note:}\) My idea is correct, and I provide the formalized answer here.

EX 19

If \(0 \le X_n \le Y_n\) and \(Y_n \xrightarrow{P} 0\), check \(X_n \xrightarrow{P} 0\).

\(\textbf{My idea:}\) Since \(0\leq X_n\leq Y_n\), so for all \(\varepsilon>0\), we have \[ \{X_n>\varepsilon\}\subseteq\{Y_n>\varepsilon\}, \] and since \(Y_n\xrightarrow{P}0\), we have \[ 0\leq P(X_n>\varepsilon)\leq P(Y_n>\varepsilon)\to0, \] that is, \(X_n\xrightarrow{P}0\).

\(\textbf{Answer:}\)

Assume \(0 \leq X_n \leq Y_n\) and \(Y_n \xrightarrow{P} 0\). We wish to show \(X_n \xrightarrow{P} 0\).

Let \(\varepsilon > 0\) be given. By the definition of convergence in probability, we must evaluate \(\lim_{n \to \infty} P(|X_n - 0| > \varepsilon)\).

Since \(0 \leq X_n \leq Y_n\), both \(X_n\) and \(Y_n\) are non-negative random variables. Therefore, \(|X_n| = X_n\) and \(|Y_n| = Y_n\). We can rewrite our target probability as \(P(X_n > \varepsilon)\).

Consider the event \(\{\omega \in \Omega : X_n(\omega) > \varepsilon\}\). Because \(X_n(\omega) \leq Y_n(\omega)\) for all \(\omega \in \Omega\), if \(X_n(\omega) > \varepsilon\), it strictly follows that \(Y_n(\omega) > \varepsilon\). This gives us the set inclusion: \[ \{X_n > \varepsilon\} \subseteq \{Y_n > \varepsilon\} \] By the monotonicity property of probability measures, if \(A \subseteq B\), then \(P(A) \leq P(B)\). Applying this to our events yields: \[ 0 \leq P(X_n > \varepsilon) \leq P(Y_n > \varepsilon) \] We are given that \(Y_n \xrightarrow{P} 0\), which means by definition \(\lim_{n \to \infty} P(|Y_n| > \varepsilon) = 0\). Since \(Y_n \geq 0\), this is equivalent to \(\lim_{n \to \infty} P(Y_n > \varepsilon) = 0\).
